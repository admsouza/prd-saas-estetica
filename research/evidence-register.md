# Registro de evidências

Use uma entrada por evidência relevante.

| Campo | Descrição |
|---|---|
| ID | Identificador único, por exemplo `EV-001` |
| Data | Data da coleta |
| Fonte | Entrevista, observação, dado operacional, avaliação pública ou benchmark |
| Perfil | Gestora, recepcionista, profissional, financeiro ou paciente |
| Dor relacionada | Identificador `DP-XX` |
| Evidência | Fato observado ou relato resumido |
| Frequência | Ocasional, recorrente ou diária |
| Impacto | Tempo, dinheiro, risco, experiência ou crescimento |
| Confiança | Fraca, moderada ou forte |
| Observações | Contradições, contexto e limitações |

## Exemplo

```markdown
## EV-001

- Data:
- Fonte: entrevista
- Perfil: recepcionista
- Dor relacionada: DP-01
- Evidência: três conversas ficaram sem resposta durante um período de pico.
- Frequência: recorrente
- Impacto: risco de perda de novos clientes
- Confiança: moderada
- Observações: validar com volume de mensagens e outras clínicas.
```

## Critérios de confiança

- **Fraca:** uma fonte indireta ou um relato isolado;
- **Moderada:** padrão repetido em fontes independentes;
- **Forte:** observação direta apoiada por dados ou recorrência ampla.

Não registre nomes de pacientes, dados clínicos identificáveis ou informações sensíveis desnecessárias.
